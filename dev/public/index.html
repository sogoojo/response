How it works:
Speech accumulates in a buffer. On silence or every N seconds, the buffer is sent to Claude which classifies it as: new question, follow-up, candidate answering, candidate struggling, or nothing. Different card types appear for each.

The server tracks conversation state — topic and questions already asked — so it won't re-trigger on restatements.
